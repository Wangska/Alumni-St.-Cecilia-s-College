═══════════════════════════════════════════════════════════════
  STEP 1: INSTALL PHPMAILER
═══════════════════════════════════════════════════════════════

Option A - Using Composer (Recommended):
─────────────────────────────────────────
1. Install Composer from: https://getcomposer.org/download/
2. Open Command Prompt or Git Bash
3. Run these commands:
   
   cd C:\xampp\htdocs\scratch
   composer install

Option B - Manual Installation:
─────────────────────────────────────────
See: INSTALL_COMPOSER.md for detailed instructions

═══════════════════════════════════════════════════════════════
  STEP 2: SETUP MAILTRAP (FREE EMAIL TESTING)
═══════════════════════════════════════════════════════════════

1. Create free account at: https://mailtrap.io
   (No credit card required!)

2. After logging in:
   • Go to "Email Testing" → "Inboxes"
   • Select your inbox (or create one)
   • Click "SMTP Settings"
   • Copy your credentials

3. Open this file in a text editor:
   C:\xampp\htdocs\scratch\inc\mailer.php

4. Find these lines (around line 10-11):
   const MAILTRAP_USERNAME = 'YOUR_MAILTRAP_USERNAME';
   const MAILTRAP_PASSWORD = 'YOUR_MAILTRAP_PASSWORD';

5. Replace with your actual Mailtrap credentials:
   const MAILTRAP_USERNAME = 'abc123def456';  // Your username
   const MAILTRAP_PASSWORD = 'xyz789uvw012';  // Your password

6. Save the file

  ❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Solution: Run "composer install" in scratch folder

Problem: Emails not showing in Mailtrap
Solution: Check credentials in inc/mailer.php

Problem: Can't install Composer
Solution: See INSTALL_COMPOSER.md for manual method
